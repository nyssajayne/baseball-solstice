# Baseball Solstice

Baseball Solstice is a playful web tool that reimagines the MLB offseason as a celestial calendar. Just as the baseball season is defined by milestones like Opening Day, the trade deadline, and the postseason, this app divides the long, quiet offseason into four quarters—mapped to the bases of a baseball diamond.

Using MLB's StatsAPI, the app calculates key dates based on a team’s final game and the next Opening Day. These "solstices" are visualized in a React + Vite frontend, offering a fun way to track the slow arc back to baseball’s return.

Visit the Schedule in action on (Github Pages)[https://nyssajayne.github.io/baseball-solstice/].

## 🛠 Tech Stack

- **Frontend:** React + Vite
- **API:** MLB StatsAPI
- **Tooling:** JavaScript, HTML, CSS

## 📦 Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/nyssajayne/baseball-solstice.git
cd baseball-solstice
npm install
```
### Other commands

Command | Description
--- | ---
`npm run dev` | Start the development server.
`npm run build`| Build for production.
